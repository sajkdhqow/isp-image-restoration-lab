## 1. AE 测光升级 (isp/ae.py)

### 做了什么

- ROI 加权测光 `ae_stats_weighted`: 支持传入权重图(人脸框/点按区域),
  (H,W) 权重自动下采样到与 Bayer 四通道同尺寸, 返回加权亮度与全图
  均值两套口径。
- 曝光三角分配: 总曝光量按 时间 → 模拟增益 → 数字增益 的顺序分配,
  噪声代价小者优先。
- 高光保护 `clip_guard`: 过曝像素占比超限时强制压低单步步长。
- 防闪烁: 曝光时间量化到灯光半周期(100/120Hz)整数倍。
- 闭环出口明确: `converged`(进容差) / `saturated`(参数到顶) / `max_iters`。

### 方法与逻辑

- AE 是闭环控制, 不改像素, 只调 sensor 参数。更新律用乘性
  `ratio = target / luma`, 单步限幅 4 倍, 防止来回穿越目标造成亮度震荡。
- ROI 加权的原理: 全图均值测光时, 逆光场景的亮背景主导统计, 主体
  (人脸)欠曝。把主体区域权重放大 x20 后, AE 收敛的判据变成"主体
  亮度达标", 背景过曝是预期代价。权重只改统计分布,
  `(ch*w).sum()/w.sum()` 对整体缩放不敏感, 所以不需要归一化绝对值。
- 为什么时间优先: 时间线性提升光通量且无噪声代价, 模拟增益会放大
  读出噪声, 数字增益纯放大不产生新信息, 代价最大所以最后用。

### 优化结果

- 基础闭环: 从欠曝 26 倍起步(t=500us), 4 次迭代收敛到
  t=4000us, ag=3.22, 亮度 17.5 → 445.1(目标 450, deadband 2%)。
- 逆光场景对比(主体区域压暗 x0.4 模拟):
  - 全图均值测光: 主体 58.9 DN, 严重欠曝。
  - ROI 加权测光: 主体 241.4 DN, 提亮 4.1 倍。t 和模拟增益到顶后
    由数字增益(约 1.8x)补足, 符合真实相机的曝光三角接力顺序。

### 剩余优化空间

- clip 统计阈值缺陷: 当前阈值 `0.97*max_val=992`, 但 BLC 后数据
  量程上限是 959(1023 减黑电平 64), 所以 clip 比例永远是 0, 高光
  保护实际未生效。迭代方向: 统计移到 BLC 前做, 或阈值改为
  `0.97*(max_val - black_level)`。注意修正后 clip_guard 会与 ROI
  测光冲突(背景高光是预期代价), 需要引入优先级仲裁(主体优先时
  关闭高光保护, 夜景灯牌场景时高光优先)。
- 测光权重目前是手工指定的固定图, 迭代方向: 接人脸检测框和点按
  坐标动态生成。
- 控制律可从"乘性限幅"升级为 PID 或步长自适应(远误差大步长,
  近误差小步长), 收敛帧数可从 4 压到 2~3。
- 收敛后参数锁定但环境缓变(日落)时, 可加入周期性微调
  (频率远低于逐帧)。

## 2. AWB 鲁棒化 (isp/awb.py)

### 做了什么

- 多假设一致性检验: 同时跑灰世界/完美反射/动态阈值三种假设,
  在 log 域算三组增益的 spread(极差)。
- 极端增益检测: 即使三假设一致, 若中位数增益超出
  `extreme_gain=2.2`, 判定为"一致性错误"(单色场景三假设会一起错)。
- 黑体轨迹投影兜底: 低置信或极端场景下, 把增益投影到普朗克轨迹
  上(t = sqrt(rgain/bgain)), 做温和校正, 宁可轻微色偏也不把画面
  拉爆。
- 3A 联动验证: 对比欠曝(近噪声底)与 AE 收敛后的 AWB 增益。

### 方法与逻辑

- 三种假设的失效场景不同(灰世界怕单色背景, 完美反射怕无白色物体,
  动态阈值怕低对比), 小误差时三者独立, 一致即高置信, 取中位数。
- 但存在"一致性错误": 大面积单色场景(草地/大海)会让三假设一起
  收敛到同一个错误答案, spread=0 但增益极端。物理上白平衡增益
  由光源色温决定, R 和 B 增益沿黑体轨迹反向变化(R 升 B 降),
  所以极端时投影到轨迹上是最物理的兜底。
- 先 AE 后 AWB 的量化依据: 欠曝时信号接近读出噪声底, 通道均值
  被噪声主导, 统计不可靠。

### 优化结果

- 草地场景(单色): 三候选全部被增益限幅 clip 到 4.00/4.00,
  spread=0 但触发极端检测, 置信度降为 low, 轨迹投影输出 R=1.000
  B=1.000, 草地保持绿色不被拉灰。
- 正常场景: spread=0.26, 置信度 high, 输出三候选中位数
  R=1.281 B=1.022。
- 联动验证: 近噪声底时 AWB 的 R 增益 1.190, AE 收敛后 1.377,
  偏差 13.6%, 证实了"AE 先收敛"的时序必要性。

### 剩余优化空间

- 轨迹投影是"最不坏"解而非正确解, 单色场景的正确答案可能是
  "不校正"。迭代方向: 场景识别(草地/大海/天空/肤色检测)给三假设
  加权, 或直接输出"该场景放弃校正"的决策。
- 色温先验: 用色温曲线约束增益搜索范围, 夜景钠灯(偏橙)场景防止
  AWB 硬拉向蓝。
- 评价体系: 当前只有定性对比, 应引入白点误差 ΔUV 指标 + 24 色卡
  测试集, 才能做参数化的回归测试。
- 混合光源(窗边人像, 一半日光一半室内灯)需要分区 AWB, 全局
  单一增益天然无解。

## 3. AF 对比度搜索优化 (isp/af.py)

### 做了什么

- 两段式(粗扫+精搜)升级为三段式: 粗扫步长 128 定峰区 → 精搜
  步长 16 爬山 → 二次精搜步长 4 在 ±16 窗口内收窄。
- 三点抛物线亚步长插值: 峰点与两侧邻点拟合顶点, 精度突破步长限制。
- 多帧平均: 每个位置采 3 帧取均值, 压掉单帧指标噪声。

### 方法与逻辑

- 对焦指标(Tenengrad, Sobel 梯度能量)在峰值附近近似抛物线, 这是
  抛物线插值成立的物理前提。
- 误差来源有三层: 步长量化误差, 插值残差, 单帧指标噪声。三段式
  压第一层(128→4), 抛物线压第二层, 多帧平均压第三层。
- 对焦指标是梯度能量, 噪声会抬高所有位置的指标基线, 所以 AF
  必须在 AE 收敛后做, 这是 3A 时序的一部分。

### 优化结果

- 对焦误差 35 → 11(占 1023 行程的 1.1%), 对比优化前(两段式单帧)
  误差 35(3.4%)。
- 成本: 35 个搜索位置 × 3 帧 = 105 次采图。位置探测(移镜+采图,
  每次几十 ms)是主要成本, 多帧只在关键窗口用是合理折中。

### 剩余优化空间

- 重复纹理(栅栏/百叶窗)的假峰未处理。迭代方向: 粗扫曲线检测
  双峰, 峰间距小于景深时判定为重复纹理, 选离上一帧对焦位置近的峰。
- 搜索路径: 粗扫可以用变步长(远误差大步长)或先验起点(上一帧
  对焦位置 ± 小范围), 预览连续变焦时位置数可从 35 压到 10 以内。
- VCM 行程时间: 搜索时镜头需要 settling time 才能稳定, 步进序列
  应考虑机械响应, 否则采到运动模糊帧污染指标。
- 指标本身: Tenengrad 对暗部梯度敏感度低, 可换成归一化方差或
  分区指标融合。

## 4. PDAF 混合 AF (isp/pdaf.py)

### 做了什么

- 虚拟 PDAF 相机: 左右半像素图 = 水平视差平移 + 离焦高斯模糊,
  视差量与离焦量成正比, 模拟真实 sensor 半掩蔽 microlens 的几何。
- 相位相关测视差: `cv2.phaseCorrelate` 直接解出 L/R 错位像素数
  与置信度。
- 方向自动标定: 按常规约定推一步, 视差变小则约定成立, 变大则
  翻转, 简化版产线 PDAF 方向标定。
- 迭代精化: 远处离焦模糊重, 视差测量偏差大, 跳到近处后重测
  1~2 次, 每次按 `est -= s*dx/k` 朝视差减小方向修正。
- 对比度精修: 在 PDAF 估计位置 ±24 的小窗口内复用三段式搜索,
  并加位置缓存, 同一位置不重复采图。

### 方法与逻辑

- 几何关系: 视差 dx ≈ 2·parallax_gain·(pos−best)/pos_range,
  换算系数 k = 2·parallax_gain/pos_range, 修正量 = dx/k(位置单位)。
  修正方向必须朝视差减小的一侧, 符号由标定统一给出。
- 本轮修复了一个符号 bug: 原实现迭代时用 `est += m*dx/k`, 其中
  `m = sign(-dx)`。当起点在对焦点近侧(dx<0)时 m=+1, 修正量变成
  `+dx/k`, 方向反了, 每次迭代把误差往外推, 粗定位从 655 越推越远
  到 787, 精修窗口内找不到真峰。修复后统一为 `est -= s*dx/k`,
  一次迭代即命中。
- 混合策略的价值: PDAF 直接测几何视差, 一次到位且不受重复纹理
  假峰影响, 对比度 AF 只负责小邻域精修, 兼得速度与精度。

### 优化结果

- PDAF 粗定位: 从 pos0=64 一步跳到 617, 正中真实对焦点。
- 最终: 精修到 607, 误差 10, 与纯对比度 AF(误差 11)持平。
- 采图: 14 帧(PDAF 采样 4 次 + 对比度精修 10 帧), 相对纯对比度
  105 帧减少 87%。真实硬件上 PDAF 的 L/R 数据与主图同帧输出,
  4 次相位采样不产生额外帧, 实际收益更大。
- 修复前对照: 粗定位 787, 精修 763, 误差 146(符号 bug 导致)。

### 剩余优化空间

- 线性 PDAF 只有一维视差信息, 斜向纹理的相关峰会漂移。迭代方向:
  全像素 PDAF 或 Quad Bayer 传感器的多方向 PDAF。
- 弱光退化: 遮挡损失一半感光, 半图噪声大, 应加置信度门限,
  response 低于阈值时回退纯对比度 AF(混合策略按置信度加权)。
- 遮挡与高反差边缘会产生 outlier 视差, 应分块相关后取中位数,
  而不是全图单一相关。
- 相位相关加 Hann 窗实测对本 demo 场景收益可忽略(测量偏差主要
  来自离焦模糊而非边缘效应), 记录在案避免重复尝试。
- 增益 k 目前假设恒定, 真实模组要做视差-离焦增益标定曲线
  (不同物距/焦距下 k 不同)。

## 5. 3A 状态机 (isp/a3a_state.py)

### 做了什么

- 四状态决策层: CONVERGING(收敛中) / CONVERGED(已收敛) /
  LOCKED(用户锁定) / RECONVERGING(重收敛)。
- 场景突变检测: 当前亮度与收敛参考值的相对差超过 0.30 判定突变,
  参考值用 EMA(系数 0.1)慢速跟随。
- 防抖: 连续 stable_frames=2 帧进容差才判收敛, 单帧噪声不触发
  状态切换。
- 锁定优先级最高: 锁定期间忽略一切统计漂移, 解锁后强制走一次
  重收敛(参数可能已不适合新场景)。
- 控制律与决策解耦: 状态机只决定"调还是不调", `ae_update` 决定
  "怎么调", 两者可独立替换。

### 方法与逻辑

- EMA 慢速跟随的作用: 正常抖动(deadband 内)不改变参考值, 缓慢
  环境渐变(日落)能跟随而不触发重收敛, 只有突变(进隧道/开灯)
  超过阈值才触发。单一固定参考值会随时间失效, 快速跟随又会让
  正常抖动触发重收敛, EMA 是两者的折中。
- 本轮修复了演示设置的两个问题:
  1. `capture` 未把数字增益喂给模拟器, AE 更新给出的 dg 实际无效,
     模拟增益到顶后画面亮度无法继续提升。
  2. 场景压暗系数 x0.35 施加在 gamma 域, 线性域等效只有 x0.1,
     需要的曝光量超出 t+模拟增益+数字增益的全部余量, 状态机永久
     卡在 RECONVERGING。改为 x0.5(gamma 域), 线性域 x0.22,
     余量内可恢复。

### 优化结果

完整走通预览流生命周期(18 帧):

```
帧 1  CONVERGED        亮度 449.6 收敛
帧 7  -> RECONVERGING  场景变暗 x0.5, 亮度跌到 98.5
帧 10 CONVERGED        3 帧完成重收敛, 亮度 449.7
帧 12 LOCKED           用户锁定, 参数冻结
帧 14 -> RECONVERGING  解锁
帧 16 CONVERGED        亮度 450.0
结束: t=4000us ag=8.00 dg=1.88 (t 与模拟增益到顶, 数字增益补足)
```

重收敛 3 帧完成, 锁定/解锁行为正确, 场景变暗后靠增益接力恢复
目标亮度。

### 剩余优化空间

- 当前只做了 AE 亮度通道。迭代方向: AWB/AF 各建子状态机, 顶层
  做优先级仲裁(用户点按 > 人脸检测 > 场景检测)。
- 场景突变是单阈值, 加进/退双阈值迟滞防止在临界亮度上状态抖动。
- AE 与 AWB 的耦合未处理: AWB 增益会改变亮度, 严格方案是 AE 用
  固定参考白平衡统计, 或 AWB 收敛后把增益影响反馈给 AE。
- 拍照瞬间(快门按下)应冻结 3A 参数(safe guard), 防止搜AF/重收敛
  过程中拍到中间状态帧。
- 状态机参数(tol/stable_frames/scene_change)目前手工设定, 应随
  场景(夜景/运动)自适应, 夜景下 tol 放宽防增益抖动。

## 统一迭代优化程序逻辑

每轮迭代遵循同一个闭环, 与 3A 的"统计-调参-重采图"结构同构:

```text
loop 每轮优化:
    1. 建基线
       固定场景集(正常/逆光/单色草地/弱光/场景突变) + 固定 seed
       跑 main.py, 记录各模块指标基线
    2. 指标仪表化
       AE:   收敛迭代数, 主体 DN, clip 比例, 收敛状态出口
       AWB:  spread, 置信度, 白点误差(待引入 ΔUV)
       AF:   对焦误差, 采图帧数, 假峰次数
       状态机: 转移序列, 重收敛帧数, 最终亮度误差
    3. 失败用例驱动
       对比期望 vs 实际, 把偏差归因到四类:
       模型错(物理假设不对) / 统计错(噪声或场景导致统计失真) /
       符号错(方向或量纲) / 参数错(阈值步长不匹配)
    4. 单变量修改 + 回归
       一次只改一处, 重跑全部场景, 指标不回退才合入
       (本轮 PDAF 符号修复验证了这一点: 改完误差 146 -> 10)
    5. 收敛判据
       指标达标, 或连续 2 轮无改善(说明到了当前框架的天花板,
       需要换方法而不是调参数), 记录到本日志
```

下一轮迭代的优先级排序(按面试展示价值与工程必要性):

| 优先级 | 项目 | 理由 |
|--------|------|------|
| P0 | clip 统计阈值修复 + 高光/主体优先级仲裁 | 当前高光保护是死代码, 修完才能讲完整的 AE 故事 |
| P0 | AWB 白点误差 ΔUV 评价 + 色卡测试集 | 没有量化指标就没有回归能力, 后续所有 AWB 迭代的前提 |
| P1 | PDAF 置信度门限 + 弱光回退对比度 | 补全混合 AF 的决策闭环, 面试高频 |
| P1 | AF 重复纹理假峰检测与回退 | 真实场景必现, 展示工程深度 |
| P2 | 3A 子状态机 + 优先级仲裁 | 架构完整性 |
| P2 | AE 控制律升级 PID/自适应步长 | 收敛帧数 4 -> 2~3 |

## 本轮修复记录

迭代过程中发现并修复的两个问题, 保留在此作为"优化不总是加功能"
的例证:

## demo 已知简化

以下简化不影响优化逻辑的正确性, 但与真实系统有差距, 面试被问到
时应主动说明:

- 离焦用高斯模糊近似, 真实是弥散圆/艾里斑 PSF。
- 数字增益折算进模拟增益喂给模拟器, 未单独建模 dg 对读出噪声的
  放大, 真实系统 dg 部分 SNR 代价更大。
- PDAF 半图是全分辨率平移生成, 真实 sensor 的 PDAF 像素稀疏排布,
  半图需要 demosaic/插值。
- clip 统计阈值缺陷(见第 1 节剩余空间), 高光保护未真实生效。
- 3A 闭环在模拟器上瞬时完成, 真实系统每帧有延迟, 需要考虑
  控制延迟与参数生效帧差。
